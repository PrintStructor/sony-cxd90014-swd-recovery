# Images

Put your own photos here (setup, needles on CL1100/CL1101, probe, camera in updater mode, MTP screen).

Before committing:
- **Remove EXIF/GPS:** `exiftool -all= -overwrite_original *.jpg` (or export without metadata)
- **No scans/crops from the Sony service manual** (copyright). Describe the location instead, or draw your own sketch.
- No serial-number stickers in the picture.
